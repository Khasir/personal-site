{% comment %} Renders an image with an optional caption, alignment, and click-to-fullscreen. Usage: {% include figure.html src="/content/images/foo.jpg" alt="A cat" caption="My cat, Whiskers" %} {% include figure.html src="/content/images/foo.jpg" alt="A cat" caption="My cat" align="right" width="320px" %} Params: src - required, path to the image (site-relative or full URL) alt - required, alt text caption - optional caption text (parsed as inline markdown, so footnotes like "My cat[^catnote]" work and merge into the post's normal footnotes list; you can also include inline HTML) align - "center" (default), "left", or "right" width - optional CSS width for left/right-aligned figures (default 40%) full - optional path to a higher-resolution version to show in the lightbox {%- endcomment %} {% assign align = include.align | default: "center" %} {% assign full_src = include.full | default: include.src %}
